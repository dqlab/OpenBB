# Extensions

In this folder you can find the extensions that were created or are supported by OpenBB.

## Collection

[Collection](collection/README.md) is the `openbb-collection` router package for
`obb.collection` and `obb.collection.live`. The independently installable engines
live beside providers under [collectors](../collectors/README.md). They retain the
`dq-historical-market-data-collector` and `dq-live-market-data-collector` CLIs.
See the collector guide for installation, provider/model configuration and tests.
